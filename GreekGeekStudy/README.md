# GreekGeek mobile app

Updated September 19, 2026. Expo 56, React Native 0.85.3, React 19.2.3, TypeScript and Expo Router. This app requires a native development build for its integrations; Expo Go is not the supported test target.

## Start development

Run from this directory. `.nvmrc` pins Node 22.13.1; the latest successful local run used Node 22.22.3.

```bash
npm ci
NODE_OPTIONS=--dns-result-order=ipv4first npx expo start --dev-client --localhost --port 8081
```

`npm ci` replaces dependencies and removes the temporary local Swift patches. Read the [native build runbook](../wiki/local-development.md) before reinstalling or rebuilding. On this Xcode 27 installation, the Expo simulator launcher does not recognize Device Hub, so use the documented direct `xcodebuild`/`simctl` workflow. The verified target is iOS 26.5; iOS 27 currently fails at launch.

`constants/api.js` currently targets `https://greekgeek.app/`. Set it deliberately to your local Django URL when testing backend changes. Metro's localhost option only changes the JavaScript server.

## Code map

- `app/`: welcome, native authentication, member tabs and admin routes.
- `context/`: authentication and dashboard state.
- `services/AccountBrowser.ts`: embedded organization registration and password recovery.
- `app/(tabs)/study.tsx`: study session and foreground/background location handling.
- `app/(tabs)/profile.tsx`: profile, subscription access and account deletion.
- `app.json`: native plugins, permissions and launch assets.
- `eas.json`: development, simulator, preview and production build profiles; remote version management and production auto-increment.

Native projects are generated by Expo Prebuild/CNG and ignored. Native dependencies or plugin changes require rebuilding the client. JavaScript-only changes can use Metro with an existing compatible client.

## Checks and release configuration

```bash
npx tsc --noEmit
npx expo export --platform ios --output-dir /tmp/greekgeek-ios-export
```

These checks do not validate native compilation, device behavior or production billing. Development RevenueCat uses a Test Store; release/TestFlight needs a production `EXPO_PUBLIC_REVENUECAT_API_KEY`. See [current state](../wiki/current-state.md), [verification](../wiki/verification-2026-09-19.md), and the [release checklist](../wiki/todo.md) for remaining gates.
